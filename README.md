# 专四阅读词汇助手

> 一个纯前端、零依赖、可离线运行的英语专业四级（TEM-4）阅读词汇统计工具。上传英文文档或粘贴段落，自动匹配专四词汇、统计词频、导出中文生词表。

![页面预览](docs/preview.png)

**在线演示**：仓库启用 GitHub Pages 后访问 `https://<你的用户名>.github.io/<仓库名>/`
**本地使用**：直接双击 `index.html`，无需安装、无需联网、无需启动服务器。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 两种输入 | ① 上传本地 `.txt` 文档（支持拖拽、自动识别常见编码）② 文本框直接粘贴英文段落 |
| 词频统计 | 英文分词后匹配专四词库，统计每个词条的出现次数 |
| 词形归并 | 自动把复数、时态、分词、比较级、副词等变化形式归并到词条原形 |
| 结果表格 | 中文表头「单词、音标、中文释义、出现次数」；支持点击表头排序、关键词筛选 |
| 一键导出 | 【导出生词表 CSV】下载当前结果，带 BOM，Excel 打开中文不乱码 |
| 原文标注 | 高亮命中的专四词汇，鼠标悬停查看音标与释义 |
| 演示辅助 | 内置示例段落一键载入；四项统计概览（总词数、命中词条数、出现总次数、占比） |

界面全部使用中文，配色清爽，适合课程作业展示。

## 快速开始

### 方式一：本地打开

1. 解压 `专四阅读词汇助手-GitHub上传包.zip`（或克隆本仓库）。
2. 双击根目录的 `index.html`。
3. 点击【载入示例段落】或上传 `examples/sample.txt`，再点【开始分析】。

> 词库已完整内联在 `index.html` 中，因此 `file://` 协议下不会出现跨域报错。

### 方式二：在线访问

按下文把文件搬到 GitHub 网站并开启 Pages，即可通过网址直接打开，方便发给同学或老师查看。

## 词库与匹配规则

- 词库共 **3000** 条专四核心词汇，每条含音标与中文释义，源文件为 `data/tem4-dict.json`。
- 页面运行时使用内联副本，不读取外部文件，保证离线可用。
- 分词后先做**精确匹配**；未命中时按规则生成原形候选（`-s/-es/-ies`、`-ed/-ied`、`-ing`、`-er/-est`、`-ly` 及双写辅音还原等），**只有候选词确实存在于词库中才会被采纳**，避免误判。
- 例如 `abandoned`、`abandons`、`abandoning` 会合并计为 `abandon` 出现 3 次；鼠标悬停表格中的单词可查看文中实际出现形式。

## 导出说明

点击【导出生词表 CSV】下载 `专四生词表_日期.csv`，列依次为：单词、音标、中文释义、出现次数。导出内容为当前筛选与排序后的结果，便于按课堂需要整理生词本。文件带 UTF-8 BOM，可直接用 Excel 打开。

## 搬到 GitHub 网站（全程网页操作，无需安装 Git）

### 第一步 · 新建仓库

登录 GitHub → 右上角 `+` → `New repository` → 仓库名填 `tem4-reading-vocab-assistant` → 选择 `Public` → **不要**勾选 `Add a README file`（避免与上传包里的 README 冲突）→ 点 `Create repository`。

### 第二步 · 上传文件

1. 解压 `专四阅读词汇助手-GitHub上传包.zip`。
2. 打开解压出来的文件夹，`Ctrl + A` 全选**里面的全部内容**，拖到仓库页 `Add file → Upload files` 的上传区。
   > 注意：拖的是文件夹内的文件，不要拖最外层文件夹，否则 `index.html` 会落到子目录，Pages 找不到首页。
3. 等待文件列表加载完，在下方填提交说明（例如「初始化项目」），点 `Commit changes`。

若浏览器未带上 `.github` 等隐藏目录，可在仓库页点 `Add file → Create new file`，文件名填 `.github/workflows/pages.yml`，把上传包中同路径文件的内容粘贴进去提交即可。该文件只影响自动部署，缺失时仍可用下方的「方式 B」开启在线页面。

**极简方案**：只上传 `index.html` 一个文件，项目就能运行（双击或开启 Pages 均可）。其余文件是说明文档、词库源文件、示例材料与维护脚本。

### 第三步 · 开启在线演示页面

| 方式 | 操作 |
| --- | --- |
| A · 自动部署（推荐） | `Settings → Pages → Build and deployment → Source` 选 **GitHub Actions**；`.github/workflows/pages.yml` 会在每次推送后自动发布 |
| B · 分支发布 | Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存即可 |

部署完成后访问 `https://<你的用户名>.github.io/<仓库名>/`，可直接把链接交给老师或同学查看。

## 二次开发

修改 `data/tem4-dict.json` 后运行：

```bash
python scripts/build.py
```

脚本会校验词条结构并把最新词库重新内联进 `index.html`。页面本身使用原生 HTML / CSS / JavaScript，不依赖任何框架、CDN 或后端服务。
